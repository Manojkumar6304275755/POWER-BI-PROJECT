Adventure Works Sales Analysis – Power BI

📊 Project Overview

This project is an interactive Adventure Works Sales Analysis dashboard developed using Microsoft Power BI. The dashboard analyzes sales performance across different time periods, customers, products, and geographic regions, helping identify revenue trends, production costs, profitability, and top-performing products.

🎯 Objectives

- Analyze overall sales and profitability performance
- Track Net Sales, Production Cost, and Profit
- Identify yearly, monthly, and quarterly sales trends
- Analyze customer-level sales performance
- Identify top-performing products
- Compare sales performance across regions
- Provide an interactive executive dashboard for business insights

🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Star Schema
- Data Visualization
- Adventure Works Dataset

🗂️ Data Model

The report uses a dimensional data model with a central fact table and supporting dimension tables.

Fact Table

- "Fact Sales Appended"

Dimension Tables

- "DimDate"
- "DimProduct"
- "Dimcustomer"
- "DimSalesTerritory"
- "DimProdCategory"

The model enables analysis of sales measures across different dimensions such as time, product, customer, product category, and geography.

📈 Dashboard Features

Executive Dashboard

The main dashboard provides:

- Total Production Cost
- Total Net Sales
- Total Profit
- Sales Amount vs Production Cost
- Year-wise Sales
- Monthly Seasonality Trend
- Top 5 Products by Sales
- Geographic Revenue Split
- Quarter-wise Sales
- Year and Quarter slicers

Sales Trend Analysis

The project includes dedicated analysis for:

- Year-wise Sales
- Month-wise Sales
- Quarter-wise Sales
- Sales Amount vs Production Cost

These visuals help understand sales trends and compare revenue against production costs.

Customer Analysis

A customer-performance view analyzes sales generated by individual customers using customer-level sales aggregation.

Product Analysis

The product-performance analysis identifies products based on their sales contribution, including a Top 5 Products by Sales view in the executive dashboard.

Regional Analysis

Sales are analyzed geographically using the Sales Territory Region dimension to understand regional revenue distribution.
